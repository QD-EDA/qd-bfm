## Behavior-failure triage

The CBD and bounded-rejection failures are test-vector length mismatches. Both Python generators emit each full 136-byte SHAKE block into `input_vectors.txt`, while truncating `exp_results.txt` to 256 coefficients. The testbenches stream the full input block, then flag valid output groups after the 256 expected values have been consumed. The pinned c339 logs show 10 such queue-underflow events for CBD and 8 for bounded rejection; preceding expected/actual values match. This identifies the vector generator/testbench boundary as the cause, rather than a demonstrated RTL mismatch. For `sigencode_z_tb`, instrumented c339 output showed zero memory writes. The minimal reproducer confirms the cause: Icarus loses the enum member when a 32-bit address expression is assigned to the 14-bit packed-struct address field, leaving write requests idle. Verilator 5.051 preserves the enum; explicitly casting the address field also preserves it on c339. The duplicate search found the matching [Icarus issue #539](https://github.com/dsellerbrock/iverilog-uvm/issues/539). The standard requires each structure assignment-pattern member expression to be evaluated in the context of that member's type (IEEE 1800-2017 §10.9.2, [standard text](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)).
