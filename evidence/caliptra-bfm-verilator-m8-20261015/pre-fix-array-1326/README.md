# Verilator timeout cohort array 1326 — pre-fix evidence

Array 1326 was stopped after the shared Caliptra runner was found to drop quoted YAML plusargs. The 14 completed result directories are preserved here with their result JSON, simulator and firmware logs, resource records, native-vector logs, and array task logs. `FILE-SHA256SUMS.txt` covers the retained run outputs. Disposable `.work` build trees and the temporary transfer archive were removed after verifying the archive hash.

The root cause was in `load_case()` in `run_caliptra_top_firmware_bfm.py`: its plusarg matcher accepted bare `+...` entries but ignored YAML entries wrapped in single or double quotes. Both `smoke_test_dma_aes_gcm_rd_enc_axi_err` and `smoke_test_dma_aes_gcm_wr_enc_axi_err` therefore launched without their three YAML-requested plusargs. Their `result.json` files show `plusargs: []` and a simulation command containing only `+CLP_REGRESSION`. Each then logged that the DMA did not report the error status expected for the configured flush, and failed the testbench assertion. These are `HARNESS-INVALID`, not valid Verilator test failures.

I checked the exact YAML and `soc_ifc.c:776` assertion on the pinned Caliptra checkout. The test YAML quotes `+CLP_DMA_TB_MODE_NOT_EMPTY` and the `+ERR_RESP_START_ADDR/END_ADDR` values; the runner supplied none. The fix is committed as `dd6d43d` (`fix: preserve quoted Caliptra test plusargs`) and has its own regression test.

Of 28 submitted rows, 12 completed as valid PASS with their logged plusargs matching YAML, two completed as the harness-invalid cases above, and 14 had no terminal result before the array was canceled. Do not count those 14 as test outcomes. The valid PASS cases were `c_intr_handler`, `iccm_lock`, `kv_entry_read_err`, `smoke_test_aes_gcm`, `smoke_test_datavault_basic`, `smoke_test_datavault_mini`, `smoke_test_dma_aes_gcm`, `smoke_test_dma_aes_gcm_cmd_err`, `smoke_test_dma_aes_gcm_collision_test`, `smoke_test_dma_aes_gcm_non_gcm_en_dec`, `smoke_test_dma_aes_gcm_short_1_dword`, and `smoke_test_dma_aes_gcm_short_dword`.

The temporary archive was copied from DAN-DESKTOP and verified against the remote SHA-256 before extraction; its hash is in `ARCHIVE-SHA256.txt`. The `ask-intern` log triage was checked against the JSON, YAML, and source assertion. It did not identify the omitted options; that cause comes from the direct comparison.
