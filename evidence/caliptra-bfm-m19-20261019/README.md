## Sampler queue-boundary compatibility overlay

Rows 56, 62, 69, and 71 reproduce their pinned-c339 queue underflows in the current-c339 array. Observation traces show the scoreboard consumes exactly 256 expected coefficients; on the next sampling edge `data_valid_o=1` while `zeroize=0` and the expected queue is empty, then zeroize rises after that edge. The benches drive zeroize from a separate posedge process using the scoreboard count, so it sees the final count one edge late.

A testbench-only compatibility overlay checks for the final valid batch (`data_valid_o && vld_coeff_ctr == 256 - <*_VLD_SAMPLES>`) and asserts zeroize after that batch. It changes no DUT/RTL, vector, expected value, comparison, or pass criterion. The one-row gate row71 (job 3129) and all four overlay rows in array 3130 pass with zero underflow messages; each finishes in under 0.1 s. Pinned-only c339 remains FAIL for the same rows, while the overlay reruns are PASS. Archives and SHA-256 sidecars are under `attempts/queue-zeroize-overlay-array-20261019-01/raw/`; trace evidence is in the sibling `queue-trace-*` attempts. A draft upstream report is preserved locally for review; nothing was posted.
