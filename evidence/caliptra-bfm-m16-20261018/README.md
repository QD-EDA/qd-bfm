## Result and limits

M16's scoped objectives are met. The MVC inventory identifies AHB-Lite QVIP as the most-used active MVC path; the existing QD-BFM replacement passes two tests in a complete generated KeyVault environment on pinned Icarus, and row 8 was re-run against the final overlay with its four-beat prediction check intact. The AHB changes affect only the testbench/BFM overlay and setup; RTL, firmware, and pass criteria are unchanged. The missing authored-test packages/vectors and local Python/NumPy setup are recorded above. Simulator defects are minimized and filed internally for A3, including the KeyVault transfer-type case (#666); nothing was posted upstream.

This milestone does not qualify all generated rows. Only KeyVault rows 6 and 8 have complete-environment runtime passes in this evidence set; row 17, PV row 46, and MLDSA row 96 remain blocked by distinct generated-toolchain issues, and several authored tests expose functional mismatches or lack trustworthy completion criteria. Row 6 is a PASS with the overlay; a pinned-only row-6 run was not performed. Its current run reports 3,170 non-fatal warnings, zero UVM errors, and zero UVM fatals.
