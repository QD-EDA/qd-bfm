## M20b root-cause correction — 2026-10-20

The exact M20-pinned Icarus binary prints `00000003` for `$display("%02X", 32'h3)`. IEEE 1800-2017 §21.2.1.3 says the field expands to contain a wider converted value and does not truncate. The root-cause layer for rows 93/97 is therefore Icarus display-format semantics; this output is standards-conforming, while the Caliptra reader assumes a one-byte opcode from a 32-bit expression. The run-local width overlay remains in place. The exact-pin transcript and five-line reproducer are in `diagnostics/display-width-exact-pin-20261020-01/`; the compatibility report is [issue #797](https://github.com/dsellerbrock/iverilog-uvm/issues/797).

## M20 follow-up — 2026-10-20

- Rows 93 and 97 share an unsized ML-DSA command-formatting defect in both predictor and driving-sequence helpers. The predictor's three `%02X` calls use `op_code-1`; the randomized sequences also write unsized literal `1` (sign) and `2` (verify). Under the M20-pinned Icarus build (`cae03564`) these produce eight hex digits such as `00000001`, while the C `readFile` routine consumes the first pair as its command byte. It therefore dispatches sign/verify input as key generation (`00`). In stopped row93 attempt03, the sequence's `signing_input_for_test.hex` begins `00000001`, its helper output begins `00` and has the keygen PK/SK layout, and the sequence reads that file into `SIG` before writing it to DUT registers. The first predictor-only overlay missed this driving-sequence path and was cancelled before verdict. The combined per-run overlay now sizes both predictor and sequence commands; rows 93/97 remain FAIL pending full row gates.
- The SV/C parser reproducer confirms the predictor's unsized `op_code-1` formats differently on the M20-pinned Icarus build (`cae03564`) and Verilator 5.032. The expanded reproducer also confirms that sequence literals `1`/`2` produce `00000001`/`00000002` under the M20-pinned Icarus build (`cae03564`) and decode as `00 00`, while Verilator 5.051 prints and decodes `01 02`; explicitly sized literals decode as `01 02` on both. The combined per-run overlay now covers the predictor and both row-driving sequences.
