The one-row gate uses `smoke_test_ecc_keygen`, which fails the seed stability assertion after a zeroize hardware clear. Job 2106 records the nonzero-to-zero transition at time 78,353,000, with `hwclr_hist=01000`, `zeroize_hist=01000`, and no software write, KV write enable, present-reset, or read-fail control. The pinned controller connects `SEED.hwclr` to zeroize, present-reset, and Key Vault read-fail. The assertion's existing disable condition omits this hardware clear and its one-cycle delayed register update.

The candidate changes only the disable condition of `ERR_ECC_SEED_NOT_STABLE` in a build-time copy of pinned `ecc_dsa_ctrl.sv`; functional RTL remains pinned. It disables the stability check on the hardware-clear cycle and the following sampled cycle, while retaining the assertion on other cycles. The generator checks the pinned source hash and requires that reversing the replacement recreates the source byte-for-byte.
